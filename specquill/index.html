Frequently Asked Questions

Does SpecQuill send webpage data to a server?

Never. All DOM inspection, CSS diffing, utility compilation, and token extraction run 100% locally in your browser. The only optional network request is verifying your Pro license key if you activate Pro.

Is this a recurring subscription? What about refunds?

No subscriptions. SpecQuill Pro is a single one-time payment with 7-day offline grace caching and a 14-day full refund policy.

Why doesn't SpecQuill ask for all-website background permissions?

SpecQuill activates only on the active tab when you click the toolbar icon, press Alt+Shift+S, or explicitly grant per-site access from the side panel.
