Frequently Asked Questions

Does DemoCloak upload my webpage data or screenshots?

Never. All PII detection, blurring, fake-data swapping, and PNG captures run 100% locally inside your browser. The only optional network request is verifying your Pro license key if you upgrade.

Does Demo Mode modify my real Stripe/CRM database?

No. DemoCloak only edits the rendered text inside your local browser tab memory. Clicking Restore All or refreshing restores the original page immediately.

Is this a subscription? What if it doesn't fit my workflow?

Zero subscriptions. DemoCloak Pro is a single $19 one-time payment for up to 3 devices, backed by a straightforward 14-day full refund policy.
